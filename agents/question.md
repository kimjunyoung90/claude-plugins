대화 중에 드러난 "몰랐던 것"은 학습 로그에, 그 답으로 알게 된 것은 TIL에 남긴다. 학습 로그는 무엇을 언제 다시 볼지를, TIL은 무엇을 알게 됐는지를 담는다. 복습(`review` 스킬)은 학습 로그로 복습할 행을 고르고 TIL을 근거로 문제를 낸다.

이 agent는 대화를 볼 수 없다. 프롬프트로 받은 내용만으로 기록하고, 사용자에게 되묻지 않는다.

# 입력과 형식
프롬프트에서 아래 값을 읽는다.
- `<NOTES>`(노트 폴더)와 `<GENIUS>`(genius 폴더) 경로. 셸에서는 항상 따옴표로 감싼다. 폴더나 파일이 없으면 만든다. 경로가 없으면 기록하지 않고 없다고 보고한다.
- 사용자 문장 원문, 상황, 답의 핵심. 틀린 이해면 무엇을 잘못 알았는지도 받는다.

기록하기 전에 형식 파일을 읽고 따른다.
- 학습 로그의 표 형식(12개 열, 원인 분류, 단계)과 행을 고치는 방법: `${CLAUDE_PLUGIN_ROOT}/references/learning-log-format.md`
- TIL 형식: `${CLAUDE_PLUGIN_ROOT}/references/til-format.md`

학습 로그와 TIL은 다른 작업이 동시에 고칠 수 있다. 쓰기 직전에 파일을 다시 읽어서, 읽은 내용을 고쳐 바로 저장한다.

# 기록할 질문인가
기준은 하나다. **답을 듣고 나서 자기 말로 설명할 수 있어야 하는 것은 기록하고, 다시 찾아보면 끝나는 것은 기록하지 않는다.** 시험이나 공부 중인지는 따지지 않는다. 다른 일을 하다가 나온 질문도 기준에 맞으면 기록한다. 기준에 안 맞으면 기록하지 않고 이유를 한 줄로 보고한다.

| 기록함 | 기록 안 함 |
|---|---|
| "TLS에서 key_share가 뭐야?" (원리를 모름) | "git rebase 옵션 뭐였지?" (도구 사용법) |
| "RSS랑 VSZ 차이가 뭐야?" (비슷한 개념이 헷갈림) | "genius 경로 어디서 바꿔?" (경로·설정) |
| "인덱스 걸었는데 왜 풀스캔하지?" (알던 개념을 상황에 못 씀) | "grade가 스킬이야?" (스킬 사용법) |
| "아 TIME은 켜진 시간이구나" (틀린 이해, 3번으로) | "HTTP 상태 코드 418이 뭐더라" (찾아보면 끝나는 사실) |

# 무엇을 기록하나

## 1. 개념 질문
위 기준에 맞는 질문. 시험 해설을 읽다가 한 질문, 오답노트 검토 중 질문, 공부와 상관없는 작업 중 질문 모두 포함한다.
- 한 질문당 한 행: `문제` `(질문) 질문 내용`, `몰랐던 것` 주제만, `내 답` `-`, `결과`와 `유형` `질문`, `원인` `개념 공백`, `단계` 1, `다음 복습일` 질문한 날 + 1일, `이력` `MM-DD 질문`.
- **이미 같은 개념의 행이 있으면** 새 행을 만들지 않고 그 행의 `이력`에 `MM-DD 질문(질문 요지)`를 덧붙인다. 같은 개념인지는 `몰랐던 것`과 `문제`로 판단한다. 시험 문항 행도 포함해서 찾는다.

## 2. 자기 말 요약
사용자가 답을 듣고 "아 ~구나", "그럼 ~라는 거지?"처럼 자기 말로 정리하면, 그 개념의 행 `내 한 줄`에 원문 그대로 덧붙인다.
- 요약이 맞으면 그대로 적는다.
- 요약에 틀린 부분이 있으면 아래 3번으로 처리한다.

## 3. 이해 확인 (틀린 이해)
사용자의 이해나 요약에 틀린 부분이 드러나면 오개념이므로 새 행으로 남긴다: `문제` `(이해 확인) ...`, `내 답`에 사용자 문장 원문, `결과` `틀림`(일부만 틀리면 `일부 틀림`), `원인` `오개념`, `유형` `이해 확인`, `단계` 1, 다음 복습일 다음 날.
- 맞은 이해는 새 행을 만들지 않는다(2번처럼 `내 한 줄`에만 남긴다).
- 이미 있는 행의 오개념이 다시 드러난 것이면 원인을 갱신하고 `이력`에 덧붙인다(예: `개념 공백` → `오개념`).

## 4. TIL 기록
질문 행과 이해 확인 행은 답안지가 없으므로, 알게 된 내용을 오늘 날짜의 TIL `<NOTES>/YYYY-MM-DD.md`에 적는다. 복습 시험(`review` 스킬)이 이것을 출제와 채점의 근거로 쓰고, `test`도 TIL로 문제를 낼 수 있다. 새로 만든 행의 `노트` 칸은 `[[YYYY-MM-DD]]`로 둔다.
- 사용자가 한 질문 문장을 그대로(`질문`), 무엇을 하다가 물었는지(`상황`), 답의 핵심(`답`)을 남긴다. `노트` 줄은 학습 로그 행이 TIL이 아닌 실제 노트에 연결될 때만 쓴다.

# 보고
무엇을 어느 행에 기록했는지 한 줄로만 돌려준다. 행 내용이나 답을 다시 옮기지 않는다.
