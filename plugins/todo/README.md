# Todo — 지라 기반 할 일 관리

할 일을 지라 티켓과 함께 관리하는 Claude Code 플러그인입니다. 할 일을 추가하면 티켓이 붙고, 시작하면 그 일을 맡을 작업 세션이 열리며, 완료하면 세션에서 한 일이 티켓에 작업 내역으로 기록됩니다. 티켓 상태(진행 중·완료)는 할 일 상태를 따라 자동으로 바뀝니다.

```
/todo:add  →  /todo:goal  →  /start  →  /check  →  /finish
할 일 추가     이번 주 목표    작업 시작    진행 확인    완료
```

전체 흐름은 아키텍처 문서 [`docs/architecture.html`](docs/architecture.html)에서 볼 수 있습니다(브라우저로 엽니다).

## 설치

```
/plugin marketplace add kimjunyoung90/claude-plugins
/plugin install todo@kimjunyoung90
```

플러그인을 켜면 지라 설정 세 가지를 묻습니다([지라 설정](#지라-설정)). 설정은 새 세션부터 적용됩니다.

필요한 도구는 `python3`와 `git`입니다. `/start`는 할 일마다 새 git 워크트리에 작업 세션을 띄우는데, 실행 환경을 스스로 고릅니다.

- [Orca](https://github.com/stablyai/orca) 안에서 `/start`를 부르고 그 레포가 Orca에 등록돼 있으면 Orca로 띄웁니다. 작업 세션이 Orca 사이드바의 지휘 세션 아래에 묶여 보입니다.
- 일반 터미널에서 부르면(Orca 앱이 켜져 있어도) Claude Code 백그라운드 세션으로 띄웁니다. `claude agents`(또는 입력창에서 `←`)로 목록을 보고 `claude attach <id>`로 들어갑니다. 워크트리는 레포 안 `.claude/worktrees/<이름>`에 만들어지며, 그 레포에서 `claude`를 한 번 실행해 폴더 신뢰를 수락해 두어야 합니다.

업데이트는 `/plugin marketplace update kimjunyoung90`, `/plugin update todo@kimjunyoung90`, `/reload-plugins` 순서로 실행합니다.

## 지라 설정

| 설정 | 내용 |
|---|---|
| 지라 주소 | `https://...` |
| 지라 계정 | 로그인 계정(이메일 또는 사용자 이름) |
| 지라 API 토큰 | 키체인 같은 OS 보안 저장소에 저장됩니다 |

주소와 계정은 `/config`에서 바꿀 수 있습니다. 바꾼 값은 새 세션부터 적용됩니다.

플러그인 설정 대신 `~/.claude/settings.json`의 `env`에 `TODO_JIRA_URL`, `TODO_JIRA_USERNAME`, `TODO_JIRA_API_TOKEN`을 넣어도 됩니다. 둘 다 있으면 플러그인 설정이 우선합니다.

지라 설정이 없어도 할 일 목록, `/todo` 화면, 목표는 쓸 수 있습니다. 티켓 생성, 상태 동기화, 작업 내역 기록만 멈춥니다.

## 사용법

| 명령 | 하는 일 |
|---|---|
| `/todo:add <할 일>` | 할 일을 추가하고 지라 티켓을 붙입니다. 티켓 키를 함께 적으면 그 티켓을 쓰고, 없으면 확인을 받은 뒤 새로 만듭니다(담당자는 나). 이미 있는 일이면 추가하지 않고 알려 줍니다. |
| `/todo` | 할 일 목록 화면을 엽니다. 이번 주 목표가 맨 위에 묶여 보이고, 오래된 할 일은 색으로 표시됩니다. 화면이 열리면 방향키(↑↓)로 할 일을 고를 수 있고, Esc 를 누르면 입력창으로 돌아갑니다. 고른 할 일에서 Enter 를 누르면 작업 세션으로 갑니다 — Orca 세션이면 그 탭으로 옮기고, 백그라운드 세션이면 `claude attach` 명령을 복사하고, 시작 전이면 입력창에 `/start <번호>`를 넣습니다. |
| `/todo:goal` | 쌓인 할 일 중에서 이번 주에 처리할 것을 골라 목표로 정합니다. 끝나지 않은 지난 주 목표는 이월로 표시됩니다. |
| `/start <번호>, ...` | 할 일마다 그 일을 맡을 작업 세션을 새 워크트리에 띄우고(Orca 또는 백그라운드 세션), 할 일을 작업 중으로 바꿉니다. 티켓은 진행 중으로 옮겨집니다. 시작 전에 레포·브랜치·실행 환경·티켓 상태를 보여 주고 확인을 받습니다. |
| `/check [번호]` | 맡긴 세션이 지금 무엇을 하는지 보여 줍니다 — 자료 조사·파일 수정 같은 작업 중인 일, 승인·입력 대기, 보고 완료, 종료. 세션을 골라 자세히 보거나 지시를 보낼 수 있습니다. |
| `/finish [티켓]` | 세션에서 한 일을 정리해 보여 주고, 확인을 받으면 날짜별 작업 시간과 정리를 티켓에 작업 내역으로 기록한 뒤 할 일과 티켓을 완료로 바꿉니다. 작업 세션 안에서는 티켓을 생략할 수 있습니다. |

번호는 `/todo` 화면의 번호입니다.

## 데이터

데이터는 `~/.claude/todo`에 저장되며, 플러그인을 지우거나 업데이트해도 남습니다. 위치를 옮기려면 `~/.claude/settings.json`의 `env`에 `TODO_DATA_DIR`를 지정하세요.

| 파일 | 내용 |
|---|---|
| `todo.jsonl` | 할 일 목록 |
| `jira/state/` | 세션과 티켓의 연결, 이미 기록한 작업 내역 |
| `jira/worklog.log` | 작업 내역 기록에 실패한 내역 |

`/finish`는 세션 기록(`~/.claude/projects`)을 읽어 작업 내역을 만듭니다. Claude Code는 기본적으로 30일이 지난 세션 기록을 지우므로, 오래 이어지는 작업이 있으면 `settings.json`의 `cleanupPeriodDays`를 늘려 두세요.
