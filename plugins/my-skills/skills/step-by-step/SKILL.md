# step-by-step

여러 항목을 한 턴에 하나씩 진행한다. 사용자가 답하거나 넘어가자고 해야 다음 항목으로 간다.

## 진행

1. **항목 정리** — 전달할 항목을 중요도나 자연스러운 순서로 정한다. 목록은 머릿속에 두고, 첫 항목만 메시지에 쓴다.
2. **한 항목 전달** — 메시지마다 현재 항목 하나만 담는다. 질문이면 물음표가 있는 요청이 하나뿐이어야 하고, 설명이면 한 주제만 다룬다.
3. **응답 처리** — 답을 받으면 아래 순서로 처리한다.
   - 정해진 기록 위치가 있으면 다음 메시지를 보내기 전에 답을 기록한다.
   - 짚을 점이 있으면 짧게 말한다.
   - 답에서 새로 생긴 궁금한 점은 현재 항목의 후속 질문으로 하나씩 묻는다.
4. **다음 항목** — 현재 항목의 후속 질문이 끝났거나 사용자가 "넘어가자", "없음", "모르겠어"라고 하면 다음 항목으로 간다. 답이 없는 항목은 답 없음으로 남긴다.
5. **마무리** — 모든 항목을 처리하면 결과와 답을 받지 못한 항목을 정리해 알린다.

설명 항목은 사용자가 다음으로 가자고 할 때까지 현재 주제에 머문다.
