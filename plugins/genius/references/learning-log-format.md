# 학습 로그 형식

genius의 모든 스킬과 agent가 따르는 학습 로그 형식의 기준이다. 스킬 폴더(`<SKILL>`) 기준으로 `<SKILL>/../../references/learning-log-format.md`에 있다.

# 파일 위치
`<NOTES>`(노트 폴더)와 `<GENIUS>`(genius 폴더)는 플러그인 설정(`userConfig`)의 값이다. 스킬은 SKILL.md에 적혀 있고, `question` agent는 호출 프롬프트로 받는다.
- 학습 로그: `<GENIUS>/학습 로그.md`
- 답안지: `<GENIUS>/.답안지/` (숨김 폴더. 시험 전에 답이 눈에 띄지 않게)
- TIL(오늘 알게 된 것): `<NOTES>/YYYY-MM-DD.md`. 형식은 `references/til-format.md`

# 표 형식
`<GENIUS>/학습 로그.md`가 없으면 아래 헤더로 만든다. 열은 12개다.

```markdown
# 학습 로그

| 날짜 | 노트 | 문제 | 몰랐던 것 | 내 답 | 결과 | 원인 | 내 한 줄 | 이력 | 유형 | 단계 | 다음 복습일 |
|---|---|---|---|---|---|---|---|---|---|---|---|
```

- **표에 정답이나 AI 해설을 적지 않는다.** 표를 열어 보는 순간 복습이 다시 읽기가 되기 때문이다. 정답과 해설은 답안지(`<GENIUS>/.답안지/`)와 TIL에만 둔다.
- `노트`: `[[노트 이름]]` 위키링크. 질문·이해 확인 행은 그 내용을 쓴 TIL(`[[YYYY-MM-DD]]`).
- `몰랐던 것`: 무엇을 몰랐는지 **주제만** 적는다(예: `ps aux의 TIME 칸이 뜻하는 것` ○, `TIME은 누적 CPU 시간` ✗). 확신 정답은 `-`.
- `내 답`: 사용자 답을 요약하지 말고 원문 그대로(길면 앞부분만) 적는다. 질문 행은 `-`.
- `원인`: 확신 정답은 비운다. 나머지는 `개념 공백`(모름) / `오개념`(확신하고 틀림) / `혼동`(비슷한 개념과 섞음) / `적용 실패`(개념은 알지만 상황에 못 씀) / `표현 부족`(방향은 맞으나 핵심 누락) / `단순 사실` / `참고함` 중 하나.
- `내 한 줄`: 사용자가 자기 말로 정리한 문장을 **원문 그대로** 적는다. 고쳐 쓰지 않는다. 여러 번 생기면 ` / `로 이어 붙인다. 없으면 `-`.
- `이력`: `MM-DD 결과`를 ` → `로 이어 붙인다(예: `10-08 오답 → 10-09 부분 → 10-13 질문(RSS는 무엇을 세나)`). 덮어쓰지 않는다. 괄호에는 **질문 요지만** 쓰고 답은 쓰지 않는다(답은 TIL로).
- `단계`: 1(1일 뒤), 2(3일 뒤), 3(7일 뒤), 4(14일 뒤), 5(30일 뒤), 6(90일 뒤), 7(180일 뒤), 졸업. 6·7단계는 오래 묵은 지식을 가끔 다시 꺼내 유지하는 단계다. 시험 결과에 따른 시작 단계와 복습 결과에 따른 갱신은 `references/grading.md`가 정한다.

# 쓰는 방법
- 노트를 찾을 때는 `<NOTES>`에서 `find`로 찾는다.
- 수정 전에 학습 로그를 스크래치패드에 백업한다.
- 행은 Python으로 고친다. 칸을 고칠 때는 `|`로 나눈 뒤 해당 칸만 바꾸고, 바꿀 행이 정확히 하나인지 확인한다(`assert`).
- 고친 뒤 모든 표 행의 열이 12개인지 확인한다.
- 새 행은 같은 노트의 행들 근처(같은 노트의 마지막 행 뒤)에 넣는다. 찾기 어려우면 표 끝에 붙인다.
