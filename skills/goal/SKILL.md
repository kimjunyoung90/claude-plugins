대상: `$ARGUMENTS`. 번호가 있으면 그 건을 바로 목표로 정하고(3단계), 없으면 1단계부터 한다.
명령: `todo.py` = `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/todo.py"`. 목표는 할 일의 `goal`(ISO 주 `YYYY-Www`)·`goal_name`(목표 이름) 칸에만 적는다. 같은 이름으로 표시한 할 일이 한 묶음이 된다.

## 1. 현황

- `todo.py todo` — 할 일 전체 (번호·id·티켓)
- `todo.py goal` — 이번 주에 이미 정한 목표와 이월(지난 주 목표인데 안 끝난 건)

이월 건이 있으면 먼저 알린다. 이어서 할지, 목표에서 뺄지(`--clear`)는 사용자가 정한다.

## 2. 후보 제안

**목표는 이번 주에 실제로 처리할 할 일이다.** 할 일이 많을 때 그중 무엇에 손댈지 정하는 것이다. 크기나 개수로 거르지 않는다 — 작은 일이라도 이번 주에 처리할 거면 목표다.

후보를 제안할 때 먼저 볼 것(위에서부터):
1. **이번 주 안에 시한이 있는 건** — 제목·note 에 적힌 날짜
2. **이미 작업 중(▶)인 건** — 이번 주에 마무리할 수 있는지
3. **오래 쌓인 건** — 접수한 지 오래된 것(화면의 ●)
4. 같은 성격의 할 일이 여럿이면 하나의 목표로 묶어 이름을 붙일 수 있다. 이때 목표 표시는 그 묶음의 할 일들에 같이 단다

**할 일 목록에 없는 일은 목표로 만들지 않는다.** 지라에 직접 계획한 일이 빠져 보이면 "할 일에 없음 — 넣으면 목표로 잡을 수 있다"고 한 줄만 알린다. 넣으려면 `/todo:add` 를 쓴다.

이렇게 보여 준다:

```
■ 목표 (안) — <YYYY-Www>
| 시한 | 목표 | 할 일 |
| <MM/DD(요일)> 또는 이번 주 | <목표 이름> | <번호>, <번호> … |
```

목표 표만 보여 준다. 목표가 아닌 할 일을 따로 나열하지 않는다.

## 3. 기록

사용자가 고르거나 고친 대로 기록한다. 번호는 기록 직전 `todo.py todo` 로 다시 맞춘다(그사이 새 할 일이 들어와 번호가 밀렸을 수 있다).

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/todo.py" goal <번호|T-id|티켓> ... --name "<목표 이름>"   # 이번 주 — 목표마다 한 번씩
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/todo.py" goal --clear <번호|T-id|티켓> ... # 목표에서 빼기
```

다음 주 목표를 미리 잡을 때만 `--week <다음 주 YYYY-Www>` 를 붙인다.

**완료 기준**: `todo.py goal` 출력을 그대로 보여 준다. `/todo` 화면 맨 위에 목표별(★ 목표 이름) 묶음으로 고정되고, 나머지 할 일은 「그 외」 아래에 그대로 남는다.
