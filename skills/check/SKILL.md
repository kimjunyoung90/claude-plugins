대상: `$ARGUMENTS` — 비어 있으면 진행 중(`in_progress`) 할 일 전부, 있으면 그 건 하나(번호는 `/start` 와 같은 번호).

## 1. 상태 수집

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" $ARGUMENTS
```

할 일마다 그 일을 맡은 Orca 세션을 찾아 상태와 마지막 보고 첫 줄을 낸다. 건 하나를 지정하면 마지막 지시와 보고 전문이 나온다.
실패하면(Orca 꺼짐 등) 메시지를 그대로 전하고 멈춘다.

| 상태 | 뜻 |
|---|---|
| 작업 중 | 에이전트가 돌고 있다. 줄에 지금 실행 중인 도구가 보인다 |
| 보고 완료 — 확인 필요 | 에이전트가 턴을 마치고 결과를 보고했다. 사용자가 읽고 다음 지시·완료를 정할 차례 |
| 입력 대기 | 권한 승인이나 질문 응답을 기다린다 |
| 중단됨 | 사용자가 끊었다 |
| 터미널 닫힘 / 세션 없음 | 맡긴 세션이 없거나 닫혔다 |

「할 일에 안 걸린 세션」은 진행 중 할 일과 이어지지 않은 세션이다 — 이미 완료한 건의 세션이 남았거나, 세션이 스스로 띄운 하위 세션이다.

## 2. 보고

전체 조회면 사용자가 손댈 건부터 묶어서 보여 준다. 스크립트 출력을 그대로 붙이지 않는다.

```
확인 필요 (N)
  <번호>. <티켓> <제목> — <어디까지 했고 무엇을 기다리는지>
입력 대기 (N)
  <번호>. <티켓> <제목> — <기다리는 승인·질문>
작업 중 (N)
  <번호>. <티켓> <제목> — <지금 하는 일>
세션 없음 (N)  <번호>, <번호> …
할 일 밖 세션 (N)  <워크트리 이름>(<티켓>, <상태>) …
```

- 「확인 필요」·「입력 대기」 건은 보고 첫 줄만으로 무엇을 기다리는지 모르면 `check.py <번호>` 로 전문을 보고 한 줄로 줄인다(결정 요청·승인 요청·결과 보고 중 무엇인지).
- 세션 없음 건은 작업이 필요하면 `/start <번호>` 로 열 수 있다고 한 줄 덧붙인다.

건 하나를 지정했으면(`$ARGUMENTS`) 이 보고를 건너뛰고 4단계로 간다.

## 3. 에이전트 고르기

세션이 있는 건(작업 중·확인 필요·입력 대기·중단)을 AskUserQuestion 으로 보여 주고 하나를 고르게 한다. 세션 없음·터미널 닫힘 건은 고를 대상에서 뺀다.

- 질문: `어느 에이전트의 작업을 볼까요?`
- 선택지 하나가 세션 하나다. 레이블은 `<번호>. <티켓> <제목>`(짧게), 설명은 `<상태> — <보고 첫 줄 또는 지금 하는 일>`.
- 선택지는 최대 4개라 확인 필요 → 입력 대기 → 작업 중 → 중단 순으로 앞의 4개만 넣는다. 더 있으면 질문 끝에 `(목록에 없는 건은 기타에 번호를 적어 주세요)` 를 붙인다.
- 고를 세션이 하나뿐이면 묻지 않고 바로 4단계로 간다. 하나도 없으면 여기서 끝낸다.
- 할 일 밖 세션은 목록에 넣지 않는다. 사용자가 기타에 워크트리 이름을 적으면 그 세션을 본다.

## 4. 고른 에이전트 자세히

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" <번호>
```

마지막 지시와 보고 전문을 읽고 아래처럼 정리한다. 보고 전문을 그대로 붙이지 않는다.

```
<번호>. <티켓> <제목> · <상태> · <마지막 활동 시각>
지시: <마지막 지시 요지>
진행: <무엇을 했는지 2~4줄>
기다리는 것: <결정·승인·질문이 있으면 그대로 옮긴다. 없으면 생략>
```

## 5. 다음 행동

고른 에이전트에 대해 할 수 있는 일을 AskUserQuestion 으로 묻는다. 상태에 맞는 것만 선택지로 넣고, 사용자가 고르기 전에는 실행하지 않는다.

- 완료 처리 (보고 완료이고 결과가 끝났을 때) → `/finish <티켓>`
- 지시 보내기 (확인 필요·입력 대기일 때) → 보낼 말을 받아 그 세션 터미널로 보낸다: `orca terminal send --terminal <핸들> --text "<보낼 말>" --enter` (핸들은 `orca terminal list` 로 찾는다)
- 다른 에이전트 보기 → 3단계로 돌아간다
- 그대로 두기 → 끝낸다

**완료 기준**: 진행 중 할 일 전부의 상태를 위 묶음으로 보고하고, 사용자가 고른 에이전트(또는 지정한 건)의 진행을 4단계 모양으로 보여 줬다.
