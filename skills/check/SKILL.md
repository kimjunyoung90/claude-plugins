대상: `$ARGUMENTS` — 비어 있으면 진행 중(`in_progress`) 할 일 전부, 있으면 그 건 하나(번호는 `/start` 와 같은 번호).

## 1. 상태 수집

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" $ARGUMENTS
```

할 일마다 그 티켓에 연결된 세션(`claude agents` 목록 + 연결 파일)을 찾는다. 세션마다 이름·마지막 활동 시각·들어가는 방법(bg 면 `claude attach <id>`)과, `▶` 줄에 지금 하는 일을 한 문장으로 낸다. 일을 마친 세션은 보고 첫 줄이 붙고, 건 하나를 지정하면 보고 전문이 나온다.
실패하면 메시지를 그대로 전하고 멈춘다.

| `▶` 문장 | 뜻 | 묶음 |
|---|---|---|
| 승인을 기다리고 있습니다 — <무엇> | 도구 실행 승인을 기다리며 멈춰 있다. 그 세션에 들어가 승인해야 이어진다 | 확인 필요 |
| 입력을 기다리고 있습니다 — <질문> | 사용자에게 물은 질문의 답을 기다린다 | 확인 필요 |
| 일을 마치고 다음 지시를 기다리고 있습니다 | 턴을 마치고 보고했다. 사용자가 읽고 다음 지시·완료를 정할 차례 | 확인 필요 |
| 자료를 조사하고 있습니다 · 파일을 고치고 있습니다 · 명령을 실행하고 있습니다 · 서브에이전트에게 맡긴 일을 기다리고 있습니다 · 답을 정리하고 있습니다 (— <무엇>) | 돌고 있다. 마지막 도구로 지금 하는 일을 말한다 | 작업 중 |
| 세션이 종료됐습니다 | 세션은 끝났고 마지막 보고만 남아 있다 | 종료됨 |
| 연결된 세션이 없습니다 | 이 티켓에 연결된 세션이 없다 | 세션 없음 |

## 2. 보고

전체 조회면 사용자가 손댈 건부터 묶어서 보여 준다. 스크립트 출력을 그대로 붙이지 않는다.

```
확인 필요 (N)
  <번호>. <티켓> <제목> — <승인 대기: 무엇 | 입력 대기: 질문 | 보고: 요지>
작업 중 (N)
  <번호>. <티켓> <제목> — <▶ 문장 그대로>
종료됨 (N)
  <번호>. <티켓> <제목> — <마지막 보고 요지>
세션 없음 (N)  <번호>, <번호> …
```

- 「일을 마치고」 건은 보고 첫 줄만으로 무엇을 기다리는지 모르면 `check.py <번호>` 로 전문을 보고 한 줄로 줄인다(결정 요청·결과 보고 중 무엇인지).
- 세션 없음 건은 작업이 필요하면 `/start <번호>` 로 열 수 있다고 한 줄 덧붙인다.

건 하나를 지정했으면(`$ARGUMENTS`) 이 보고를 건너뛰고 4단계로 간다.

## 3. 에이전트 고르기

세션이 있는 건(작업 중·확인 필요·종료됨)을 AskUserQuestion 으로 보여 주고 하나를 고르게 한다. 세션 없음 건은 고를 대상에서 뺀다.

- 질문: `어느 에이전트의 작업을 볼까요?`
- 선택지 하나가 세션 하나다. 레이블은 `<번호>. <티켓> <제목>`(짧게), 설명은 `▶` 문장(일을 마친 건은 보고 첫 줄).
- 선택지는 최대 4개라 확인 필요 → 작업 중 → 종료됨 순으로 앞의 4개만 넣는다. 더 있으면 질문 끝에 `(목록에 없는 건은 기타에 번호를 적어 주세요)` 를 붙인다.
- 고를 세션이 하나뿐이면 묻지 않고 바로 4단계로 간다. 하나도 없으면 여기서 끝낸다.

## 4. 고른 에이전트 자세히

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" <번호>
```

`▶` 문장과 보고 전문을 읽고 아래처럼 정리한다. 보고 전문을 그대로 붙이지 않는다.

```
<번호>. <티켓> <제목> · <마지막 활동 시각>
지금: <▶ 문장>
진행: <보고에서 무엇을 했는지 2~4줄. 아직 보고가 없으면 생략>
기다리는 것: <승인·질문·결정 요청이 있으면 그대로 옮긴다. 없으면 생략>
```

## 5. 다음 행동

고른 에이전트에 대해 할 수 있는 일을 AskUserQuestion 으로 묻는다. 상태에 맞는 것만 선택지로 넣고, 사용자가 고르기 전에는 실행하지 않는다.

- 완료 처리 (보고 완료이고 결과가 끝났을 때) → `/finish <티켓>`
- 승인·답하러 들어가기 (승인·입력 대기일 때) → 아래 「들어가서 보기」와 같다. 승인과 질문 답은 메시지로 대신할 수 없다
- 지시 보내기 (일을 마쳤거나 작업 중일 때) → 보낼 말을 받아 `SendMessage` 로 그 세션 이름에 보낸다. 두 세션의 권한 모드가 다르면(한쪽만 권한 확인 생략) 받는 쪽에 보류된다 — 그러면 그 세션에서 승인하거나 직접 들어가 입력하라고 알린다
- 들어가서 보기 → bg 면 `claude attach <id>` (또는 `claude agents`), Orca 면 사이드바에서 그 세션을 연다
- 다른 에이전트 보기 → 3단계로 돌아간다
- 그대로 두기 → 끝낸다

**완료 기준**: 진행 중 할 일 전부의 상태를 위 묶음으로 보고하고, 사용자가 고른 에이전트(또는 지정한 건)의 진행을 4단계 모양으로 보여 줬다.
